# PDF Único

Ferramenta gratuita para unir, organizar e compactar arquivos PDF diretamente no navegador, sem instalação.

🔗 **Acesse a ferramenta:** https://epitaciosouza.github.io/compilar-pdf/

## Funcionalidades

- Seleção de vários arquivos PDF
- Organização dos documentos na ordem desejada
- União dos arquivos em um único PDF
- Reordenação por arraste ou pelos controles da lista
- Remoção individual de documentos antes do processamento
- Diferentes níveis de compactação
- Download imediato do arquivo gerado
- Funcionamento direto no navegador
- Contador público de acessos

## Como utilizar

1. Abra a ferramenta pelo link acima.
2. Arraste os PDFs para a área indicada ou clique em **Selecionar PDFs**.
3. Organize os documentos na ordem desejada.
4. Escolha o nível de compactação.
5. Clique em **Unir PDFs agora**.
6. Baixe o arquivo final.

## Níveis de compactação

- **Tamanho original:** mantém textos, vetores e a qualidade original.
- **Leve:** reduz o arquivo preservando boa qualidade.
- **Equilibrada:** opção recomendada para compartilhamento.
- **Forte:** busca o menor tamanho possível.

## Privacidade

O processamento dos PDFs acontece localmente no dispositivo. Os documentos não são enviados para o GitHub nem armazenados em um servidor.

O contador registra somente a abertura da página e não recebe o conteúdo dos arquivos selecionados.

## Compatibilidade

Utilize uma versão atualizada do Google Chrome, Microsoft Edge, Mozilla Firefox ou outro navegador moderno.
